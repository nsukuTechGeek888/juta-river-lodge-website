# Juta River Website Prototype

Open `index.html` in a browser to preview the mobile-first Juta River website.

## Image filenames to use

Replace/add real photos inside `assets/` using the names below.

- `hero_event.jpg` — wide hero photo: a real Juta River crowd/event at night, ideally with lights and the venue visible.
- `venue_main.jpg` — wide daytime venue photo: pool, eating house, outdoor seating or river area.
- `venue_night.jpg` — wide night-time venue/event photo.
- `food.jpg` — close-up food/restaurant photo.
- `drinks.jpg` — drinks/bar photo.
- `gallery_01.jpg` through `gallery_06.jpg` — best real photos from events, venue, food and atmosphere.

The supplied posters are already included and are used as event-card images.

## Important

The current WhatsApp and ticket links are placeholders. Replace them with the owner's real WhatsApp number and the correct ticketing links.

The event dates/prices shown are taken from the supplied posters and should be confirmed by the owner before publishing.
