THE JUTA RIVER WEBSITE PROTOTYPE

This is a mobile-first static website built for The Juta River Lodge.

FILES
index.html  Main page
styles.css  Responsive design
script.js   Mobile menu + event countdown
assets/     Event posters and the supplied venue photo

IMPORTANT
The venue section uses the actual venue photo supplied by the client/user.
No additional food/gallery/venue photos are required for this prototype.

TO PUBLISH ON GITHUB PAGES
1. Upload all files and the assets folder to your repository.
2. Settings > Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: / (root).
6. Save.

Replace the placeholder contact/ticket details when the owner supplies the real information.
